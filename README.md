# Databricks Lakeflow Declarative Pipelines – Retail Data Pipeline

An end-to-end retail data pipeline built using **Databricks Lakeflow Declarative Pipelines (LDP)**, demonstrating the **Medallion Architecture (Bronze, Silver, and Gold)**, data transformations, and data quality management.

## 📌 Overview

This repository contains the source code for my YouTube video on **Databricks Lakeflow Declarative Pipelines (LDP)**.

In this project, we build an end-to-end retail data pipeline using the Medallion Architecture to demonstrate how LDP simplifies data transformation, orchestration, and data quality management.

## 📚 Concepts Covered

- Lakeflow Declarative Pipelines fundamentals
- Pipelines, Flows, and Datasets
- Streaming Tables and Materialized Views
- Medallion Architecture
- Data Quality Expectations
- End-to-end retail data processing

## 🏗️ Architecture

The pipeline follows the **Medallion Architecture**:

- 🥉 **Bronze:** Raw retail data
- 🥈 **Silver:** Cleaned and standardized data
- 🥇 **Gold:** Aggregated daily sales insights
